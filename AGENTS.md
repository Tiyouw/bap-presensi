# Aturan kontribusi

- Setiap PR yang mengubah UI wajib menyertakan screenshot sebelum dan sesudah
  secara inline di deskripsi PR, sebelum PR ditandai siap atau di-merge.
- Bandingkan layar, viewport, dan keadaan data yang sama. Sertakan HP dan desktop
  jika keduanya terdampak. Ambil gambar sebelum dari kode base PR yang sebenarnya.
- Gunakan data sintetis; jangan publikasikan roster mahasiswa, NIM asli, token,
  password, atau environment rahasia dalam gambar maupun fixture.
- Gunakan `.github/pull_request_template.md`. Untuk PR tanpa dampak visual,
  jelaskan mengapa screenshot tidak berlaku.
